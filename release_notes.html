Issue #1 Resolved

Feature release adding target completion date (due date) capabilities to the Todo application.

Summary of Changes

  • Database & Models: Added optional due_date column to the Todo model.
  • Schemas: Updated TodoCreate, TodoUpdate, and TodoResponse schemas with the due_date field.
  • API Endpoints: Extended create and update routes to handle target completion dates.
  • Frontend UI: Added date picker input to the task creation form and updated task list item rendering to display due dates.
