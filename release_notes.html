Todo Application Release Notes

Feature: Task Due Date Support (Resolves #1)

Overview

This release implements target completion dates for tasks, addressing Issue #1.

Key Changes

  • Database Model: Added due_date (Date) column to SQLAlchemy Todo model.
  • Pydantic Schemas: Updated TodoCreate, TodoUpdate, and TodoResponse schemas to accept and return optional due_date.
  • API Endpoints: Updated /todos endpoints with support for due dates and complete docstrings.
  • Frontend UI: Added date picker input in task creation form and due date badge indicator on task cards.
