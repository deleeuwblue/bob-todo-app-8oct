Todo App v1.1.0

Released: 5 October 2025  ·  Branch: feature/issue-1-due-date

New Features

  • Due date for tasks — Tasks now support an optional complete-by date. Set it when creating a task using the date picker in the UI. (Closes #1)
  • Overdue indicator — Tasks whose due date has passed are highlighted in red with an ⚠ prefix so they stand out immediately.

Backend Changes

  • Model — Todo ORM model gains a nullable due_date (Date) column.
  • Schema — TodoCreate and TodoResponse schemas updated to include the optional due_date field.
  • Router — POST /todos now accepts and persists due_date; all endpoints have full docstrings added.

Frontend Changes

  • Add form — A date picker input has been added alongside the task title field. Due date is optional.
  • Task list — Each task now displays its due date beneath the title. Overdue tasks render the date in red.
  • Rendering — Task items restructured with a .todo-body container to stack title and due date vertically.

Fixed

  • Issue #1 — Tasks had no way to record or display a completion deadline.

Upgrade Notes

  • The todos table gains a new due_date column. Delete todos.db and restart the server to recreate the schema, or run a migration manually.
