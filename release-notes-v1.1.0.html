Todo App v1.1.0

Released — branch: feature/issue-1-due-date  ·  Resolves #1

What's New

  • Due date on tasks — every task can now be given a target completion date when it is created. (#1)
  • Due date display — the date is shown inline on each task card. Overdue tasks (not yet completed, past their due date) are highlighted in red.
  • Optional field — due date is not required; existing tasks without a date are unaffected.

Changes

  • app/models.py — added nullable due_date (SQLAlchemy Date column) to the Todo model.
  • app/schemas.py — added optional due_date: Optional[date] to TodoCreate and TodoResponse.
  • app/routers/todos.py — create_todo now passes due_date from the request payload to the model.
  • static/index.html — added a date picker input to the add-task form; task cards display the due date with overdue styling.

Database

  • Schema recreated to include the new due_date column. Existing todos.db must be dropped and recreated on upgrade.
