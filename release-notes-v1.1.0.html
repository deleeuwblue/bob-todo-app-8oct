Todo App — Release Notes

v1.1.0

Released:  |  Branch: feature/complete-by-date  |  Resolves: Issue #1

What's New

  • feat Complete-by date — tasks now support an optional deadline date set at creation time.
  • feat Due date display — each todo item shows its deadline below the title in a muted label.
  • feat Overdue highlighting — incomplete tasks past their deadline are highlighted in red.

Changes by Component

  • backend app/models.py — added complete_by (Date, nullable) column to the todos table.
  • backend app/schemas.py — TodoCreate, TodoUpdate, and TodoResponse all include the new optional complete_by field.
  • backend app/routers/todos.py — create_todo and update_todo persist and return complete_by.
  • frontend static/index.html — date picker added to the add-task form; due date rendered per item with overdue colouring.
  • chore Docstrings added to all public functions and API endpoints per project standards.

Migration

  • The existing todos.db was dropped and will be recreated on next server start with the updated schema.
  • No manual migration steps required for a fresh install.
